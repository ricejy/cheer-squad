# cheer-squad

A mod for Claude Code: a rice-wine look with rice grains drifting up the
background, and a squad of costumed stickmen who line up down both sides of
the chat and cheer while Claude works.

- **While Claude works** two long lines of stickmen fill the sides of the
  window, top to bottom, doing a stadium wave under falling confetti:
  cheerleaders with pom-poms between idol fans waving glow sticks, flag bearers
  with a 必勝 ("certain victory") flag, World Cup fans in face paint and
  scarves, foam-finger fans and drummers, with "GO CLAUDE!" and "THINK BIG!"
  signs.
- **While Claude rests** the stands are empty and only the rice grains drift.
- The colours are milky rice paper by day and dark earthenware by night, with
  celadon accents.
- A soft item-pickup chime plays when Claude finishes a turn or needs your
  attention. It uses PowerShell on Windows, `afplay` on macOS, and `paplay` or
  `aplay` on Linux. On Windows it needs Git Bash, which Claude Code's hooks use.

## Token weather row

The row above the prompt box shows three pills: the context window (its
weather, tokens and the trend of recent prompts), the 5-hour limit and the
7-day limit, each against the time elapsed in its window. It is a trimmed copy
of [Token Weather Usage](https://github.com/augiefra/claude-mods) by Eric
Cologni: the prompt-cache, cost and running-agents pills are left out. If the
original Token Weather Usage plugin is on too, this mod hides its row so only
one shows.

## Good to know

- The mod is made for the Claude desktop app, which draws the backdrop. In a
  terminal the backdrop is not drawn.
- The squad is placed for the desktop app with its sidebar open. With the
  sidebar closed it sits a little to the right of the chat.
- The mod sets its look at the start of every turn, so it overrides any other
  theme mod running in the same session, such as rice-wine. Turn one of them
  off.

## Install

At the prompt of a terminal session:

```
/plugin install cheer-squad --marketplace ricejy/cheer-squad
```

Answer `y` to add the marketplace, then pick a scope (user, for every session).

From a shell:

```
claude plugin install cheer-squad --marketplace ricejy/cheer-squad
```

In the desktop app, where `/plugin` does not run: click + next to the prompt
box, then Plugins, Add marketplace with `ricejy/cheer-squad`, then Add plugin.
